# MEYA — Politique de confidentialité

Politique de confidentialité de l'application mobile MEYA
(Google Play : `com.meya.app`).

MEYA permet de partager et valoriser les actions positives pour
l'environnement aux Comores : plantations d'arbres, nettoyages,
sensibilisation et initiatives communautaires.

**Page en ligne :** https://TONPSEUDO.github.io/meya-privacy/
